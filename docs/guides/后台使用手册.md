## 1. 访问与登录

**访问地址**：`https://your-domain/admin`

访问 `/admin` 下任意路径时，系统自动检查登录状态：

- **未登录** → 跳转至 `/admin/login`
- **已登录** → 正常访问

### 1.1 登录

在登录页输入管理员密码（由服务器 `ADMIN_PASSWORD` 环境变量配置）。

- 密码正确 → 自动跳转控制台
- 密码错误 → 显示错误提示，计入失败次数
- **连续失败 5 次** → 触发 30 分钟冷却，冷却期结束后自动解锁

> 冷却期间页面会显示剩余等待时间（秒）。

### 1.2 登出

点击侧边栏底部的「退出登录」按钮，即可清除 Session 并跳转至登录页。

## 2. 控制台（Dashboard）

访问地址：`/admin/dashboard`

控制台分为三个区域：

| 区域 | 说明 |
|---|---|
| **同步与发布状态** | 最近一次任务的执行结果与发布状态 |
| **手动同步** | 配置并手动触发同步任务 |
| **定时任务配置** | 设置自动同步的时间计划 |
| **最近任务** | 历史任务列表，含步骤详情与日志 |

页面每 **5 秒**自动刷新数据，也可点击右上角「刷新状态」手动刷新。

## 3. 手动同步

### 3.1 选择同步表

在「手动同步」卡片中，勾选本次需要同步的表：

| 表名 | 飞书表 | 产物文件 |
|---|---|---|
| 地点 | 飞书地点多维表格 | `src/config/locations.json` |
| 故事 | 飞书故事多维表格 | `src/data/content.json` |
| 创作公示板头表 | 飞书便签头表 | `src/data/creation-board-headers.json` |
| 创作公示板 | 飞书创作公示板表格 | `src/data/creation-board.json` |
| 鸣谢名单 | 飞书鸣谢名单表格 | `src/data/contributors.json` |

- 点击「使用默认表」：恢复为定时任务配置的默认表组合
- 点击「全选表」：选中所有表

### 3.2 依赖处理方式

| 选项 | 说明 | 适用场景 |
|---|---|---|
| **仅读本地依赖**（默认） | 只同步所选表；依赖数据从本地已有文件读取 | 日常轻量刷新 |
| **执行依赖表** | 自动将依赖表补入执行队列 | 需要同时更新依赖数据时 |
| **严格模式** | 依赖表未被选择或本地不存在时直接失败 | 验证数据完整性 |

> `stories` 表依赖 `locations`；`creation_board` 表依赖 `creation_headers`。若依赖数据也有更新，选择「执行依赖表」可自动补入执行队列。

### 3.3 其他选项

| 选项 | 说明 |
|---|---|
| **处理附件并回写 OSS URL** | 下载飞书附件、上传至 OSS、将 OSS URL 回写飞书；关闭后跳过附件处理，使用飞书已有 URL 字段 |
| **单表失败后继续执行** | 某张表同步失败时，是否继续执行剩余表 |
| **备注** | 可选填写，说明本次同步的原因，显示在任务记录中 |

### 3.4 触发同步

配置完成后点击「**同步数据**」按钮：

- 任务立即创建，后台开始执行
- 界面会在数秒内显示任务状态（自动轮询）
- 任务执行期间按钮变灰，同时不可再次触发

> **同步数据**只更新服务器上的 JSON 文件，**不影响线上页面**。要让线上页面展示新内容，需要「同步并发布」。

## 4. 同步并发布

点击「**同步并发布**」按钮，任务完成数据同步后继续执行：

1. **构建**（`npm run build`）：重新编译站点，打包最新数据
2. **重启服务**（`pm2 restart web`）：切换至新版本
3. **健康检查**：等待服务恢复正常响应

全部步骤完成后，线上页面即展示最新内容。

**发布状态说明**

| 状态 | 说明 |
|---|---|
| 发布中 | 构建/重启正在执行 |
| 已发布 | 发布成功，线上已更新 |
| 发布失败 | 构建或重启失败；**线上页面保持不变，不受影响** |

> 构建失败时，服务器继续运行旧版本，不会导致页面中断。

## 5. 定时任务配置

在「定时任务配置」卡片中设置自动同步计划。

### 5.1 启用/关闭定时任务

通过「启用定时任务」开关控制。关闭后调度器停止，不再自动触发同步。

### 5.2 Cron 表达式

使用标准 5 段 Cron 表达式（`分 时 日 月 周`）：

| 示例 | 含义 |
|---|---|
| `0 2 * * *` | 每天凌晨 2:00 |
| `0 */6 * * *` | 每 6 小时执行一次 |
| `0 8 * * 1` | 每周一早上 8:00 |
| `*/30 * * * *` | 每 30 分钟 |

> 注意：定时任务默认只执行「同步数据」，不触发构建与重启。如需自动发布，将「默认任务类型」设置为 `sync-data-and-publish`（需谨慎，构建耗时较长）。

### 5.3 默认同步表与任务类型

定时任务执行时使用的表和类型。建议保持合理范围，避免每次全量刷新带来不必要的 OSS 费用。

保存调度配置时可选择「保存依赖策略」：选择「执行依赖表」会自动补齐默认同步表依赖，适合将 `creation_board` 与 `creation_headers`、`stories` 与 `locations` 成组保存。

### 5.4 保存配置

修改后点击「**保存调度配置**」按钮，配置立即生效（调度器热更新，无需重启）。

点击「**恢复服务器配置**」：丢弃未保存的修改，恢复当前服务器配置。

**下次执行时间**：Cron 输入框下方实时显示调度器计算的下次执行时间。

## 6. 查看任务记录与日志

### 6.1 任务列表

「最近任务」区域展示最近 12 条任务记录，每条记录包含：

- 任务 ID、任务类型（同步 / 同步并发布）、创建时间
- 状态徽标（颜色区分状态）
- 请求表 / 实际执行表
- 依赖模式、附件处理、继续执行设置
- 同步完成时间 / 发布时间 / 开始/结束时间

**状态颜色含义**

| 颜色 | 状态 |
|---|---|
| 蓝色 | 执行中 / 发布中 |
| 绿色 | 成功 / 已发布 |
| 橙色 | 部分成功 / 待发布 |
| 红色 | 失败 / 发布失败 |
| 灰色 | 排队中 / 已跳过 |

### 6.2 任务汇总

展开任务后显示汇总数据：

- 总记录数 / 成功 / 跳过 / 失败
- 地点数 / 故事数 / 创作记录数
- 写入的文件列表

### 6.3 执行步骤

每个表模块作为一个独立步骤展示，包含：

- 开始 / 结束时间
- 成功 / 跳过 / 失败记录数
- Warnings（非致命问题，如记录缺字段、附件处理失败等）
- Errors（致命问题，导致该步骤失败）

### 6.4 查看日志

点击任务记录底部的「**查看日志**」按钮，展开该任务的原始执行日志（最后 200 行）。

日志以深色终端样式展示，包含每一步详细的时间戳和操作记录，便于排查问题。

再次点击「收起日志」关闭。

## 7. 内容数据查看

访问地址：`/admin/content`

查看当前服务器上的产物 JSON 文件内容（读取构建期数据，反映最近一次同步结果）。

### 7.1 三个 Tab

| Tab | 数据来源 | 内容 |
|---|---|---|
| **地点与故事** | `src/data/content.json` | 地点列表 + 各地点包含的故事 |
| **创作公示板** | `src/data/creation-board.json` | 创作灵感投稿记录 |
| **鸣谢名单** | `src/data/contributors.json` | 参与贡献者名单 |

切换 Tab 时搜索框自动清空。

### 7.2 搜索

右上角搜索框支持关键字过滤：

| Tab | 搜索范围 |
|---|---|
| 地点与故事 | 地点名、地点 ID、角色名、作者、故事内容 |
| 创作公示板 | 作者、内容、标签 |
| 鸣谢名单 | 姓名、角色、留言 |

### 7.3 故事展开

地点与故事 Tab 中，每条故事记录可点击「展开」查看完整内容与大图链接。

## 8. 公告配置

访问地址：`/admin/announcement`

管理前台「活动公告」弹窗（导航栏及页脚公告入口点击后弹出的飞书文档内嵌窗口）。

### 8.1 文档链接

填写飞书云文档 URL，格式示例：

```
https://xxx.feishu.cn/docx/<docId>
```

保存后，所有用户下次打开公告弹窗时即加载新文档。

### 8.2 界面功能开关

界面按文档分为以下区块，每项对应飞书 SDK `setFeatureConfig` / 构造器 `config` 的 `extensions.*` 字段：

| `suiteNavBar.docComponentHeader.height` | 导航栏高度（数字 px，留空不设置） |

**协作者 (collabAvatar)**

| 字段 | 说明 |

**更多菜单 (moreMenu)**

| 字段 | 说明 |

| `moreMenu.enable` | 显示「⋯」菜单入口 |

## 9. 常见问题

### 同步成功了，但线上页面没有变化？

这是正常现象。「同步数据」只更新服务器文件，**不触发构建**。  
要让线上页面展示新内容，需点击「**同步并发布**」。

---

### 点击同步后出现「已有任务运行中」提示？

当前已有另一个任务正在执行（同一时刻只允许一个任务）。  
等待当前任务完成后再试，或在任务列表中查看正在运行的任务进度。

---

### 任务状态长时间停留在「执行中」？

可能原因：
1. 同步任务本身耗时较长（正常，飞书数据量大或 OSS 上传慢时可能需要数分钟）
2. 进程异常退出导致锁未释放

若任务超过 30 分钟仍未完成，锁会自动过期，之后可以重新触发同步。

---

### 发布失败了，线上会崩溃吗？

不会。`publishStatus = publish_failed` 表示构建失败，**线上服务保持运行旧版本**，访客不受影响。  
可在任务详情的「发布」步骤中查看具体错误原因，修复后重新触发「同步并发布」。

---

### 定时任务没有自动执行？

检查以下项：
1. 「定时任务配置」中「启用定时任务」是否开启
2. Cron 表达式是否正确（可用 [crontab.guru](https://crontab.guru) 验证）
3. 调度器随 Node.js 进程启动，若服务重启后定时任务未恢复，检查 `src/instrumentation.ts` 是否正常初始化（`NEXT_RUNTIME === "nodejs"` 条件）

---

### 如何查看最近一次同步写了哪些文件？

在任务记录中查看「**任务汇总**」区域的「输出文件」字段，或展开各步骤的「写入文件」项。

---

### 内容数据页面显示的是最新数据吗？

是的，内容数据页面直接读取服务器上的 JSON 文件（`src/data/`），反映**最近一次同步**的结果。  
这与线上页面不同：线上页面展示的是**最近一次构建时**打包进去的数据。

如需确认线上与服务器数据一致，在同步完成后执行「同步并发布」。

---

### 修改了公告配置，但弹窗仍显示旧文档？

公告弹窗每次**打开时**实时从服务器拉取配置，无需重启或构建。  
若刷新后仍未变化，检查：
1. 是否已点击「保存配置」
2. 浏览器 F12 → Network，确认 `/api/announcement-config` 返回最新的 `docUrl`

---

### 公告弹窗的飞书 SDK 功能开关不生效？

飞书 SDK 同时通过两个途径接收配置：
- 构造器 `config` 字段（在组件初始化时传入）
- `setFeatureConfig()` 方法（在 `start()` 后调用）

两者均已实现。若仍不生效，可能是该 SDK 版本对特定字段支持有限，确认飞书 `docComponentSdk` CDN 版本是否与文档一致。
