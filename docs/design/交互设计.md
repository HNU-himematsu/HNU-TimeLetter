# 交互设计与页面逻辑 (Interaction Design)

本文档定义了“与她的海大时光笺”的核心交互逻辑与用户体验设计。

## 1. 全局体验 (Global Experience)

### 1.1 开场仪式 (Intro Page)
用户进入网站时的第一印象，旨在建立沉浸感并传达项目理念。当前版本保留启封主屏，并在未开信状态下于首屏下方接入“关于企划 / 关于我们 / 鸣谢 / 页脚”下滚页面群；完成开信过渡后，再切换到地图 / 集邮册主体验。

#### 启封主屏 (The Envelope)
- **视觉**: 
  - **网格**: 首屏基于五列竖向网格排版，丝带贴合第一列右边界，标题居于第二列，信封居于右侧三列的中心。
  - **标题**: 左侧采用竖排标题“与她的海大时光笺”，与整高红色丝带并置，形成首屏识别锚点。
  - **核心**: 右侧展示信封主体，火漆印使用实物质感素材，信封采用固定尺寸主视觉。
- **交互**: 
  - **点击信封**: 
    - **动画**: 火漆碎裂 -> 封盖翻开与信纸抽出 -> 信封壳体整体下落 -> 信纸移动到视口中心并放大铺满 -> 过渡遮罩淡出 -> 主界面显示。
    - **状态**: 点击后先进入 `opening` 阶段，并在信纸放大前开启 `isTransitioning` 过渡遮罩；动画完成后设 `isEnvelopeOpened = true`，再由页面层延时收起遮罩。
  - **层级衔接**: 封盖翻开后，其 `zIndex` 由 `30` → `0` 的切换通过 `framer-motion` 延迟 `0.15s` 执行，避开信纸放大瞬间封盖仍压在信纸之上的视觉缺口。
- **入场动效**:
  - **丝带**: 首次进入页面时基于 `clip-path` 执行自上而下的垂直裁剪显影，不改变位置与尺寸，采用双层 `requestAnimationFrame` 触发，时长 `1400ms`，缓动为 `cubic-bezier(0.16, 1, 0.3, 1)`。
  - **信封**: 与丝带同时以 Spring 方式自上方飘落，落定后进入轻微呼吸浮动。
  - **标题**: 标题在丝带动画完成后淡入；进入开信阶段时同步上移并轻微模糊淡出。
  - **火漆**: 火漆印在待机态保持固定 `-5deg` 倾角，不提供 hover / tap 形变反馈.
- **滚动策略**:
  - 未开信状态下，首屏下方直接承接“关于企划 / 关于我们 / 鸣谢 / 页脚”信息页面群。
  - 桌面端在启封态下使用 Lenis 提供平滑滚动并隐藏原生滚动条；移动端保持原生纵向滚动。
  - 这些信息页面属于启封态内容层，开信完成后会整体切换到地图 / 集邮册主体验。

### 1.2 响应式分流 (Responsive Strategy)
采用 **双端差异化体验** 策略，而非简单的 CSS 响应式缩放。
- **PC 端 (>768px)**: 进入 **[时光画卷 (Desktop View)](#2-pc-端-时光画卷)**。
- **移动端 (≤768px)**: 进入 **[掌心集邮册 (Mobile View)](#3-移动端-掌心集邮册)**。
- **实现**: 在 `app/page.tsx` 与 `app/map/page.tsx` 中根据屏幕宽度条件渲染不同组件树。

### 1.3 独立路由扩展 (Additional Route)

- **首页 `/`**: 承载启封主屏与下滚页面群，服务于进入站点时的仪式化浏览入口。
- **地图主体验 `/map`**: 承载桌面端交互式地图与移动端掌心集邮册主体验，由开信过渡或全局导航进入。
- **创作公示板 `/creation`**: 承载群友共创灵感的公开浏览页，服务于“灵感沉淀与延展”，不与首页主展陈内容混用。
- **数据策略**: `/map` 与 `/creation` 一样，均基于飞书同步后的本地静态数据渲染。

### 1.4 全局导航栏 (Global Navigation Bar)

> 导航栏以轻量悬浮姿态常驻于视口右上角，跨越所有页面保持位置不变，服务于"主页 / 地图 / 公示板"三个顶层路由之间的切换。

#### 定位与外形

- **位置**: `position: fixed`，锚定于视口右上角，不随页面滚动偏移。
- **形态**: 竖向排列的胶囊长条（Vertical Pill），高度由内部选项数量撑开，宽度恒定。
- **尺寸不变性**: 胶囊容器的宽度与高度在所有页面、所有状态下保持一致，不因路由切换或页面个性化而缩放或变形。各页面的定制仅作用于胶囊之外的附加装饰层（如首页的红色色块），不得修改胶囊本体尺寸。
- **容器外观**:
  - **背景**: 磨砂玻璃（`backdrop-filter: blur`）；底色参考 `Surface` 色系并降低不透明度，保留穿透感。
  - **描边**: `1px solid #c23643`（Primary 红），赋予情感锚点，区别于通用玻璃组件。
  - **圆角**: 完整胶囊圆角（`border-radius` 为宽度的 50%），使长条呈现上下封口的药丸外形。
  - **层级**: `z-index` 高于页面主内容，低于模态框与全局遮罩。

#### 导航选项

- **数量**: 三个，固定顺序从上至下排列：
  1. 主页
  2. 地图
  3. 公示板
- **文字方向**: 竖排（`writing-mode: vertical-rl`），每个选项占据胶囊条中的一个分段。
- **字体**: 使用标题字体 `ChillDINGothic_SemiBold`，字号视竖排胶囊宽度定。
- **文字颜色**:
  - 未选中：`Ink` 色 `#5a4748`（默认），`Ink Muted` 色在 hover 态稍加过渡。
  - 选中：白色 `#ffffff`，配合红色选中背景保持对比度。

#### 选中态

- **选中选项**背景为实心红色胶囊，颜色 `#c23643`（Primary）。
- 胶囊**内嵌于容器之中**，左右两侧与容器内壁保留相等缝隙（padding），不与容器等宽，视觉上呈现「胶囊套胶囊」的层次感。
- 高度包裹选项文字并在上下方向留有内边距，圆角与容器整体胶囊保持视觉协调。
- 选中态切换通过布局动画过渡（`layout animation`），胶囊平滑滑动至新激活项，不做硬切换。

#### 路由对应

| 选项   | 路由         | 说明                           |
|--------|--------------|--------------------------------|
| 主页   | `/`          | 启封主屏及下滚页面群入口       |
| 地图   | `/map`       | 开信后的交互式地图主体验       |
| 公示板 | `/creation`  | 群友共创灵感浏览页             |

> **注意**：导航栏激活态以路由为主：`/` 对应“主页”，`/map` 对应“地图”，`/creation` 对应“公示板”。首页内部的启封状态与滚动态不再承担地图主体验的路由判定职责。

#### 各页面个性化

各页面对导航栏的视觉定制（如背景透明度、位置微调、入场时机等）在各自的页面设计小节中单独描述，本节仅定义跨页共享的全局规格。

#### 首页导航栏个性化 (Homepage Variant)

首页（`/`）的导航栏根据滚动状态呈现两种视觉形态：

**开屏态（页面未滚动 / `scrollY === 0`）**
- 导航栏胶囊容器底部附加一块红色 `#c23643` 长方形色块，紧接在胶囊容器正下方。
- **尺寸**：高度约为视口高度的 30%（`~30vh`），宽度与导航栏胶囊容器等宽（约为视口宽度的 7%，`~7vw`）。
- **圆角**：**仅左下角为圆角**，其余三个角（左上、右上、右下）保持直角；左上与右上紧贴胶囊容器底边，视觉上二者无缝衔接。
- 此色块与首屏左侧的红色丝带形成横向呼应，强化整体视觉框架。

**滚动态（页面开始向下滚动后）**
- 上述红色底部色块随滚动距离淡出至完全透明，导航栏回归全局通用的磨砂玻璃 + 红色描边外观。
- 过渡应平滑（淡出动画），避免颜色骤变。

#### 公告按钮 (Announcement Button)

胶囊导航条正下方附加一个圆形跳转按钮，固定显示于所有页面（后台管理路由除外）。

- **形态**: 正圆形（`border-radius: 50%`），直径与胶囊容器宽度一致（`clamp(44px, 4vw, 64px)`）。
- **外观**: 与胶囊容器保持相同材质——磨砂玻璃（`backdrop-filter: blur`）+ 半透明底色 `rgba(246, 241, 235, 0.55)` + `1px solid #c23643` 红色描边。
- **Hover 态**: 背景由透明亚克力渐变为实心红 `#c23643`，文字颜色随之由 `#563B3B` 变为白色 `#ffffff`；过渡时长 `0.2s`。`prefers-reduced-motion: reduce` 时切换瞬间完成，无过渡动画。
- **文字**: 「公告」两字，水平居中，字体与胶囊选项一致（衬线字体，`tracking-[0.18em]`）。
- **跳转**: 点击在新标签页打开 `https://himematsu.feishu.cn/docx/EbsDdehuLo1801xBzb1cxzJLnHb`。
- **间距**: 与胶囊容器底部之间留 `0.5rem`（Tailwind `gap-2`）间距。

## 2. PC 端: 时光画卷 (Desktop View)

> **核心隐喻**: “横向展开的时光画轴” —— 沉浸、动态、叙事。

### 2.1 交互式地图与卷轴 (Interactive Map & Scroll)
- **布局策略**: 
  - **初始状态 (Idle)**: 地图全屏显示，用户可以在地图上寻找地点。
  - **卷起动作 (Rolling)**: 点击地点 Pin 后，地图从左侧向右侧水平收纳，最终在右侧边缘形成一个宽 56px 的 **[卷轴条 (Scroll Strip)](#23-卷轴条视觉设计)**。
  - **收纳逻辑**: 地图容器使用 `overflow-hidden` 裁剪，内层地图保持 `100vw` 宽度并右锚定，确保收纳过程中 Pin 点的相对坐标依然准确。
- **层级关系 (Layering)**:
  - 为了保证交互体验，**故事面板 (z-30)** 位于 **地图/卷轴容器 (z-10)** 之上。
  - 这确保了在故事面板中拖拽卡片时，卡片可以自由覆盖在卷轴条上，不会产生视觉遮挡或被裁剪。

### 2.2 故事看板 (Story Stage)
- **出现时序**: 
  - **顺序感控制**: 故事看板不会在地图开始卷起时立即出现，而是等待地图完全收纳成卷轴（即 `rolled` 状态）后才开始进场。
  - **进场动画**: 采用从下方弹出的弹簧动画（Spring），无内部延迟，确保地图卷完后立即无缝衔接。
- **核心交互**:
  - **堆叠卡片 (Card Stack)**: 位于看板中心，支持向左/向右拖拽飞出，循环展示。
  - **底层卷轴**: 卷轴条始终位于右侧背景，作为返回地图的常驻入口。

### 2.3 卷轴条交互 (Scroll Strip Interaction)
- **还原逻辑**: 点击右侧卷轴条触发 `unrolling` 状态。
- **顺序感**: 
  1. 故事看板首先执行退场动画（向上飞出并淡出）。
  2. 看板完全退出后，地图容器开始向左展开恢复至 `100%` 宽度。
  3. 状态重置为 `idle`，激活地点清空。

## 3. 移动端: 掌心集邮册 (Mobile View)

> **核心隐喻**: “手中的集邮册” —— 高效、私密、易读。

### 3.1 故事瀑布流 (Story Feed)
- **策略**: 移动端以垂直瀑布流承载主体阅读路径，不加载交互式地图组件。
- **卡片**: 展示高清大图缩略 + 地点/角色信息。
- **FAB (悬浮按钮)**: 右下角常驻“地图”图标按钮，点击弹出一张 **纯静态海大地图** 图片，仅供查看地理位置，不可交互。

### 3.2 沉浸阅读 (Detail Modal)
- **转场**: 点击列表卡片 -> **共享元素转场 (Shared Element Transition)** -> 图片放大至全屏。
- **布局**: 上图下文。
  - **上部**: 高清大图 (占据约 50% 高度)，覆盖左右切换箭头。
  - **中部**: 角色头像与信息区。
  - **下部**: 滚动阅读故事文本。
- **手势**:
  - **点击箭头**: 切换同一地点的不同故事。
  - **左右滑动**: 切换不同地点。
  - **下拉 (Pull-to-close)**: 关闭详情页返回列表。

## 4. 下滚页面群 (Scroll-down Pages)

> **核心隐喻**：启封主屏下方向外延展的“展览走廊”——用户在未开信状态下即可继续向下浏览，完成开信后则切换到地图 / 集邮册主体验。

### 4.0 全局滚动系统

#### 平滑滚动 (Smooth Scroll)
- **桌面端策略**：启封态下由 Lenis 接管桌面端滚轮滚动，提供带惯性的平滑过渡；移动端保持原生滚动。
- **关键参数**：`duration: 1.2`、指数型 easing、`wheelMultiplier: 1`、`touchMultiplier: 2`。
- **辅助样式**：通过 `html.lenis` / `.lenis-scrolling` 等状态类隐藏原生滚动条，并处理停止态与滚动态样式。
- **实现位置**：`src/lib/useVirtualScroll.ts` 与 `src/app/globals.css`。

#### 自定义滑块 (Custom Scrollbar)
- **定位**：原生滚动条由 `globals.css` 隐藏后，由 `src/components/shared/CustomScrollbar.tsx` 渲染一条与 Lenis 严格同步的 DOM 滑块；仅在桌面端启封态且页面可滚动时挂载。
- **视觉**：轨道固定视口右侧 `15px` 宽、透明背景；滑块宽 `10px`、高度按 `vh × (vh / 文档高)` 动态计算，圆角 5px。默认为透明填充 + `1px #c23643` 描边，鼠标悬停时填充为实心 `#c23643`。
- **驱动**：优先通过 `lenis.on('scroll', ({ scroll, limit }))` 同步位移，无 Lenis 实例时回退到 `window.scroll` 监听；`ResizeObserver` 同步高度与可滚动性。
- **事件区分**：轨道 `pointer-events: none`，滑块 `pointer-events: auto`，避免影响页面其他交互。

#### 红色引导线 (Red Guide Line)
- **视觉**：横跨“关于企划 → 关于我们 → 鸣谢”三个页面的折线引导线，宽度 `100px`，颜色 `#c23643`，端点圆角（`stroke-linecap: round`, `stroke-linejoin: round`）。
- **层级**：位于背景之上、正文内容之下（`z-index: 1`）；首页 `page-paper` 会遮住起点上方延伸段。
- **路径定义**（`ribbonX = vw * 0.2 - 50px` 与丝带中心精确对齐；y 坐标为各自 section 高度占比，与 `GuideLine.tsx` 中 `recalculate()` 的实际实现一致）：
  - 关于企划页：`P1(ribbonX, apTop)` → `P2(ribbonX, apTop + apH * 0.10)` → `P3(19.15%vw, apTop + apH * 0.125)` → `P4(107.5%vw, apTop + apH * 0.4043)`
  - 关于我们页：不新增节点，由 `P4 → P5` 的对角长段跨越
  - 鸣谢页：`P5(-2.19%vw, crTop + crH * 0.654)` → `P6(32%vw, crTop + crH + 80)`
- **起点与首屏衔接**：`P1` 精确落在首屏底边（= 丝带视觉终点）下方，保证用户刚开始下滑即可看到引导线从丝带下方伸出，无“空走”段。
- **可视裁剪 (Mask)**：SVG 视口的顶/底边由 `GuideLine.tsx` 硬裁剪：
  - 顶边 = `P1.y - 60`，保留圆角端点的视觉余量。
  - 底边 = `creditsBottom`（= 鸣谢页底边 = 页脚交界线），`P6` 故意被放到 `creditsBottom + 80`，超出蒙版的部分由 `overflow: hidden` 吞掉，从而让 stroke 主体无论角度都能严丝合缝地贴到交界线上，尾部视觉“归到页脚红带”。
- **动效逻辑**：非可逆单向 **y-aware 进度映射** + 三段 anchor 策略
  - 以视口基准线 `refY = scrollY + vp * anchor` 在折线上的 y 位置反查长度，确保描边终点与视口中的观察位置精确对齐（避免线性进度在路径几何不均匀时“甩在视口外”）。
  - **启动段** (`scrollY ≤ 500px`)：`anchor = 1.0` 跟视口底；超出后该分量冻结，交棒给中段。
  - **中段** (`500 < scrollY < transitionStart`)：`anchor = 0.6`，尾部锁在视口 60%。
  - **尾段** (`scrollY ≥ transitionStart = 0.7 × snapScroll`)：`anchor` 从 `0.6` 线性过渡到 `1.0`，尾部沉到视口底与页脚交界汇合。
  - **触底 snap**：一旦 `viewBottom ≥ creditsBottom`，进度强制 `1.0`。
  - **非可逆性**：用 `Math.max(cachedMaxProgress, currentProgress)` 冻结历史最远端，向上回滚不会收回已经曝光的描边。
- **实现**：一条连续 SVG `<path>` 依次连接 `P1 → P6`，其中 `P4 → P5` 对角跨越整个“关于我们”页面；详见 [GuideLine.tsx](../../src/components/shared/GuideLine.tsx)。

### 4.1 关于企划 (About Project)
- **布局**：全屏（`100vh`），信纸色背景。
- **文案**：
  > 关于企划
  >
  > 这是一个聚焦于海大校园、由群友灵感驱动的 AIGC 视觉共创展。

  > 这不仅一次单向的画集展示，更是一场属于我们的集体记忆创作。我们以这方校园为画框，邀你一同拆开这封跨越虚实的"海大时光笺"。
- **排版**：标题使用标题字体（`font-serif`），正文使用正文字体（`font-sans`），大留白风格。

### 4.2 关于我们 (About Us)
- **布局**：全屏（`100vh`），左右分栏，并主动避让从右上到左下穿越的引导线。
- **左侧**：成员职责文案区
  - **固定文案**（始终显示在左侧顶部）：

## 6. 创作公示板 `/creation` (Creation Board)

> 详细方案见 [创作公示板](./创作公示板.md)。

### 6.1 页面目标

- 用于集中展示群友们已公开的共创灵感。
- 让后续创作可以直接站在已有灵感之上继续补充，而不是从零散聊天记录中重新翻找。

### 6.2 页面结构

- 顶部为标题区，仅承载标题与一句简短说明。
- 标题区下方直接进入便签式瀑布流，页面不引入分栏、侧边栏或筛选面板。
- 页面主体以“轻网格草稿线背景 + 便签卡片瀑布流”构成。

### 6.3 卡片与布局

- 灵感内容以便签条样式展示，卡片高度随内部堆叠内容自然变化。
- 卡片底色为随机马卡龙色系，每张卡片一个色调。
- 卡片外轮廓为直角，不使用圆角。
- 列表采用瀑布流布局，形成创作墙般的高低错落效果。
- 一张卡片对应一个 `CardID`，同 `CardID` 的多条记录在卡片内部垂直堆叠。
- 卡片右上角固定展示常驻的白色 `新增创意` 按钮，按钮需预留独立空间，点击后打开带当前 `CardID` 预填值的飞书表单。
- 每条堆叠项的左上角为 `author`，右上角为胶囊 `tags`，主体根据标签展示 `content` 或 `images`。

### 6.4 交互原则

- 默认以扫读为主，点击后再进入完整阅读。
- 动效应轻盈克制，以抬升、归正、阴影变化为主，不做强弹跳。
- 手机端优先保留内容可读性，必要时缩减列数，不强求桌面端的展板密度。
