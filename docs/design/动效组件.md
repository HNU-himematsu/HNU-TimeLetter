# 动效组件 (Motion Components)

> **版本号**: v1.0.0
> **状态**: 2026-05-14 已实施
> **实现路径**: `src/components/motion/`
> **动画引擎**: Framer Motion v12（项目已安装，`package.json` 中声明）

## 概述

动效组件目录（`src/components/motion/`）集中管理站点级的交互动效组件，包括磁吸交互按钮、高阶延迟追踪光标及共享鼠标追踪 Hook。所有组件遵循以下架构原则：

- **数据分离**：事件回调仅更新 `useMotionValue`（内存变量），不触发 React 重渲染；渲染由 framer-motion 内部 Ticker 驱动。
- **GPU 加速**：所有位移动画元素应用 `will-change: transform`。
- **可访问性**：尊重 `prefers-reduced-motion`，该偏好下所有动效静默禁用。
- **制品写作规范**：所有注释为「现状描述」风格，不依赖对话上下文，不使用比较性/变更性用语。

## 1. 磁吸交互按钮 (MagneticButton)

**文件**: `src/components/motion/MagneticButton.tsx`

### 1.1 功能描述

鼠标悬停时，按钮整体跟随鼠标产生磁吸位移，内部填充层滑入，文本色彩翻转；鼠标离开时按钮弹性回弹至原位，填充层滑出，文本色彩延迟恢复。

### 1.2 DOM 层级结构

```
<外层容器>               — overflow: hidden，裁剪溢出内容
  <磁吸交互层>           — mousemove / mouseenter / mouseleave 事件监听
    <填充层 Fill>        — translateY 控制显隐（76% → 0% → -76%）
    <文本位移层>         — 独立磁吸视差位移
      <文本色彩层>       — 悬停时触发 color 翻转
        {children}
```

### 1.3 动效参数

| 交互场景 | 物理参数 | 持续时间 | 缓动函数 |
|---------|---------|---------|---------|
| 鼠标跟随（按钮位移） | 归一化坐标 × `strength` | 1.5s | `cubic-bezier(0.25, 1, 0.5, 1)` (Power4.easeOut) |
| 鼠标跟随（文本位移） | 归一化坐标 × `textStrength` | 1.5s | 同上 |
| 鼠标离开（回弹） | spring: `stiffness=350, damping=8, mass=0.5, restSpeed=0.5` | — | 弹簧物理引擎 (Elastic.easeOut) |
| 填充层进入 | `y: 76% → 0%` | 0.6s | `cubic-bezier(0.45, 0.05, 0.55, 0.95)` (Power2.easeInOut) |
| 填充层退出 | `y: 0% → -76%` | 0.6s | 同上 |
| 文本色彩进入 | 暗 → 亮 | 0.3s | `cubic-bezier(0.7, 0, 0.84, 0)` (Power3.easeIn)，无延迟 |
| 文本色彩退出 | 亮 → 暗 | 0.3s | `cubic-bezier(0.22, 0.89, 0.38, 1)` (Power3.easeOut)，延迟 0.3s |

**退场延迟说明**：文本色彩退出设置 0.3s 延迟，确保填充色块在视觉上退出过半后再触发色彩恢复，避免闪烁。

### 1.4 Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `children` | `ReactNode` | — | 按钮文本内容 |
| `className` | `string` | — | 外层容器附加 className |
| `fillClassName` | `string` | `'bg-[#171717]'` | 填充层背景色 |
| `textClassName` | `string` | — | 文本位移层附加 className |
| `textInnerClassName` | `string` | — | 文本色彩层附加 className |
| `strength` | `number` | `100` | 磁吸位移强度（像素）。归一化偏移 [-0.5, 0.5] × 该值 = 实际位移 |
| `textStrength` | `number` | `strength × 0.5` | 文本层独立磁吸强度（产生视觉视差） |
| `colorScheme` | `'change' \| 'change2' \| 'change3' \| null` | `'change'` | 色彩方案预设 |
| `magneticBreakpoint` | `number` | `540` | 磁吸激活的最小视口宽度（px） |
| `as` | `ElementType` | `'button'` | 渲染元素类型（如 `'a'` 或 Next.js `Link`） |
| `href` | `string` | — | 链接地址 |
| `onClick` | `() => void` | — | 点击回调 |
| `disabled` | `boolean` | `false` | 禁用交互 |

### 1.5 色彩方案

| 方案 | 文本色（默认） | 文本色（悬停） | 适用场景 |
|------|-------------|-------------|---------|
| `'change'` | `#171717` | `#FFFFFF` | 深色文字在浅色背景上 |
| `'change2'` | `#000000` | `#C9FF85` | 黑色文字 + 嫩绿高亮 |
| `'change3'` | `#FFFFFF` | `#000000` | 浅色文字在深色背景上 |

设为 `null` 可完全禁用色彩动画。

### 1.6 响应式行为

窗口宽度 ≤ `magneticBreakpoint`（默认 540px）时磁吸位移静默禁用，但填充层位移与文本色彩动画保持正常运行。断点守卫通过 `window.resize` 事件实时响应。

### 1.7 架构约束

- `useMotionValue` 持有所有位移目标值，不写入 React State，避免 mousemove 高频事件触发全局重渲染。
- `animate()` 每次调用自动覆盖前一次同 `MotionValue` 的动画，等效 GSAP `gsap.to()` 的补间覆盖机制。
- 填充层使用独立 `MotionValue`（`fillY`），与磁吸位移的 `mx/my/tx/ty` 分属两条动画管线，互不干扰。

## 2. 高阶延迟追踪光标 (StickyCursor)

**文件**: `src/components/motion/StickyCursor.tsx`
**挂载位置**: `src/app/layout.tsx` → `<body>` 顶层（`site-frame-shell` 之外）

### 2.1 功能描述

在视口顶层渲染两个固定定位的圆形图层，以独立的延迟阻尼系数追踪鼠标位置。外圈（48px）LERP 除数 12（高粘稠延迟），内点（10px）LERP 除数 6（低延迟快速响应），产生分层追踪的视觉效果。

### 2.2 LERP 插值算法

每帧（`requestAnimationFrame`）执行：

```
outerX += (mouseX - outerX) / OUTER_DIVISOR   // OUTER_DIVISOR = 12
innerX += (mouseX - innerX) / INNER_DIVISOR   // INNER_DIVISOR = 6
```

除数越大，光标图层对鼠标位置变化的响应越慢，视觉上的粘稠延迟感越强。外圈（除数 12）产生显著的拖尾感，内点（除数 6）更紧密地跟随实际光标位置。

### 2.3 反色滤镜

光标图层使用 **SVG `feColorMatrix` 滤镜** + **CSS `backdrop-filter`** 实现站点调色反色：

```svg
<filter id="color-swap-filter">
  <feColorMatrix type="matrix" values="
    -1  0  0  0  1.68627
     0 -1  0  0  1.12549
     0  0 -1  0  1.15686
     0  0  0  1  0
  " />
</filter>
```

矩阵对每个 RGB 通道取反（× -1）后叠加站点主题色偏移量。`backdrop-filter` 对光标圆形区域内的背景像素执行滤镜，实现逐像素混合：

| 背景色 | 滤镜输出 | 视觉效果 |
|--------|---------|---------|
| 深色 `(0, 0, 0)` | `(1.69, 1.13, 1.16)` → clamp 白 | 光标呈白色，在深色背景上清晰可见 |
| 浅色 `(1, 1, 1)` | `(0.69, 0.13, 0.16)` → `#af2028` | 光标呈站色调暗暖色，与页面色彩体系协调 |

对比 `mix-blend-mode: difference` 的通用差值混合，`feColorMatrix` 方案通过自定义偏移量使反色结果与站点主题色精准匹配，而非机械的通道减法。

### 2.4 z-index 层级

光标 `z-index: 9999`，位于站点画框描边层 `site-frame-border`（`z-index: 10001`）之下。此设计确保画框 5px 白色描边始终在光标之上，光标不会侵入画框边缘，符合全站视口画框体系（参见 [全站视口画框](./全站视口画框.md)）。

### 2.5 公告弹窗联动

光标组件订阅 Zustand store 的 `isAnnouncementOpen` 状态。当飞书公告弹窗开启时，光标 DOM 不渲染（返回 `null`），隐藏自定义光标，用户看到浏览器原生光标。弹窗关闭后光标恢复渲染。

**联动原因**：飞书 SDK 创建的跨域 iframe 会截获 `mousemove` 事件（浏览器跨域安全策略），父窗口无法接收 iframe 内部的鼠标坐标。若光标继续渲染，会在 iframe 边界处定格，视觉效果不理想。隐藏光标是主动规避策略。

RAF LERP 循环在弹窗开启期间保持运行（仅 DOM 不渲染），弹窗关闭时光标已追踪到最新位置，恢复后无位置跳变。

### 2.6 触摸设备处理

首次渲染后通过 `window.matchMedia('(pointer: fine)')` 检测输入设备类型。触摸设备（无精确指针）上光标不渲染。

## 3. 全局鼠标追踪 Hook (useMousePosition)

**文件**: `src/components/motion/useMousePosition.ts`

### 3.1 功能描述

在 `window` 上以 passive 模式监听 `mousemove` 事件，将 `clientX` / `clientY` 写入 framer-motion `MotionValue`。`MotionValue` 属于外部可变值存储，其变更不触发 React 组件重渲染，仅驱动 framer-motion 内部动画管线更新已绑定的 DOM 属性。

### 3.2 返回值

| 字段 | 类型 | 说明 |
|------|------|------|
| `mouseX` | `MotionValue<number>` | 鼠标视口 X 坐标 |
| `mouseY` | `MotionValue<number>` | 鼠标视口 Y 坐标 |

### 3.3 使用示例

```tsx
import { useMousePosition } from '@/components/motion'

function MyComponent() {
  const { mouseX, mouseY } = useMousePosition()
  // 可传入 useSpring / animate 或直接绑定到 motion.div 的 style
}
```
