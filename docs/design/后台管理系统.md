# 后台管理系统设计文档 (Admin System Design)

> **版本**: v2.0.0
> **状态**: 已实现
> **受众**: 内部开发人员

## 1. 功能概述

后台管理系统集成在 Next.js 项目内，提供以下能力：

- 浏览器操作飞书数据同步（手动触发 / 定时任务）
- 查看同步任务执行记录与日志
- 浏览站点内容数据（地点故事、创作公示板、鸣谢名单）
- 调度器配置（Cron 表达式、开关、默认表）
- 活动公告弹窗配置（文档链接 + 飞书 SDK 界面功能开关）

## 3. 鉴权模块

### Session 机制

- Cookie 名称：`admin_auth`，`HttpOnly; Secure; SameSite=Lax`
- Token 算法：`HMAC-SHA256(userId + ":" + expiresAt, ADMIN_SESSION_SECRET)`
- 有效期：7 天
- 环境变量：
  - `ADMIN_SESSION_SECRET`：签名密钥，生产环境要求 ≥32 字节随机字符串
  - `ADMIN_PASSWORD`：管理员密码，生产环境应通过环境变量注入，不可使用默认值 `admin`

### 限流

- 基于内存 Map，key = `IP:UserAgent`
- 5 次连续失败 → 封禁 30 分钟
- 窗口期 1 小时，过期记录每 1 小时自动清理（防内存泄漏）
- 429 响应包含 `retryAfterSeconds` 字段

### Middleware

`src/middleware.ts` 拦截 `/admin/` 路径（`/admin/login` 除外），通过 `checkAuth()` 校验 Cookie，未通过则重定向 `/admin/login`。

## 4. 同步任务系统

### 4.1 任务模型

| 字段 | 说明 |
|---|---|
| `jobId` | `sync-{timestamp}-{随机4位}` 格式唯一 ID |
| `kind` | 固定为 `sync-data` |
| `status` | `queued → running → success / partial_success / failed` |
| `steps[]` | 每张表一个步骤，各自记录 status/summary/warnings/errors |
| `tables` | 请求同步的表（用户选择） |
| `effectiveTables` | 依赖解析后实际执行的表顺序 |
| `summary` | 全局汇总（totalRecords / successRecords / filesWritten 等） |

### 4.2 表注册表

| key | 说明 | 依赖 |
|---|---|---|
| `locations` | 飞书地点表 | 无 |
| `stories` | 飞书故事表 | `locations` |
| `creation_board` | 创作公示板 | 无 |
| `contributors` | 鸣谢名单 | 无 |

### 4.3 依赖处理模式

| 值 | 说明 |
|---|---|
| `read_local` | 只同步所选表，依赖表从本地产物读取 |
| `run_dependencies` | 自动补跑依赖表 |
| `strict` | 缺依赖即失败，不补跑也不读取 |

### 4.4 锁机制

`runtime/admin/sync-lock.json` 记录当前占用锁的 `jobId`，防止并发运行。
- 超时时间：30 分钟（`SYNC_LOCK_TIMEOUT_MS` 环境变量可覆盖）
- 并发创建任务时抛出 `SyncConflictError`，API 返回 409

### 4.5 文件持久化

任务记录存储于 `runtime/admin/sync-jobs/<jobId>.json`，上限 100 个文件，超出自动清理最早记录。

### 4.6 任务日志

同步过程中的详细日志写入 `logs/sync/<jobId>.log`。
日志读取接口：`GET /api/admin/sync/jobs/<jobId>/logs`，返回最后 200 行。

## 5. 调度器

- 库：`node-schedule`
- 初始化：`src/instrumentation.ts` 在 `NEXT_RUNTIME === 'nodejs'` 时调用 `initScheduler()`
- 接口：
  - `startSyncJob(cron)` — 启动/替换定时任务
  - `stopSyncJob()` — 停止定时任务
  - `getNextRunAt()` — 返回下次执行时间 ISO 字符串（未运行时返回 null）
- 下次执行时间通过 `GET /api/admin/sync/config` 的 `nextRunAt` 字段返回

---

## 6. 运行时数据生效路径

同步任务完成后，前端通过运行时 API 读取最新 JSON 产物文件：

```
飞书多维表格
    ↓ 同步任务
src/data/*.json / src/config/*.json
    ↓ 运行时 API
前端页面
```

JSON 产物文件更新后，内容页面与前台页面会读取最新数据，不需要构建或重启服务。

`/admin/content` 页面读取以下文件并提供 Tab 浏览与关键字搜索：

| Tab | 数据文件 | 搜索字段 |

## 8. API 接口一览

| Method | Path | 功能 |
|---|---|---|
| POST | `/api/admin/login` | 登录，成功设置 Cookie |
| DELETE | `/api/admin/login` | 登出，清除 Cookie |
| GET | `/api/admin/sync/config` | 读取调度配置 + 运行时摘要 + 下次执行时间 |
| PATCH | `/api/admin/sync/config` | 更新调度配置（同时热更新调度器） |
| GET | `/api/admin/sync/jobs` | 任务列表（`?limit=N`，最大 100） |
| POST | `/api/admin/sync/jobs` | 创建并异步执行任务 |
| GET | `/api/admin/sync/jobs/:jobId` | 任务详情 |
| GET | `/api/admin/sync/jobs/:jobId/logs` | 任务日志（最后 200 行） |

## 9. 环境变量参考

| 变量名 | 必填 | 说明 |
|---|---|---|
| `ADMIN_PASSWORD` | 是 | 登录密码，不可使用默认值 `admin` |
| `ADMIN_SESSION_SECRET` | 生产必填 | Session 签名密钥，≥32 字节 |
| `SYNC_RUNTIME_DIR` | 否 | 任务记录目录，默认 `runtime/` |
| `SYNC_LOG_DIR` | 否 | 日志目录，默认 `logs/sync/` |
| `SYNC_LOCK_TIMEOUT_MS` | 否 | 锁超时，默认 1800000（30 分钟） |
| `SYNC_WEBHOOK_SECRET` | 否 | Webhook 触发同步的鉴权密钥 |
