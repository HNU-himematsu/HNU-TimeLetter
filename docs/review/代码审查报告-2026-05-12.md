## 一、Bug（已识别，按优先级排序）

### B1 — 登录页不处理限流响应 ✅ 已修复
**文件**: `src/app/admin/login/page.tsx`

原 `handleLogin` 只判断 `res.ok`，不区分 `401`（密码错误）和 `429`（频率限制），且提交期间缺少 `loading` 状态保护。已修复为：区分 429 响应并展示重试等待秒数，提交期间禁用按钮。

### B2 — 侧边栏缺少退出登录入口 ✅ 已修复
**文件**: `src/app/admin/(protected)/layout.tsx`

`DELETE /api/admin/login` 已实现但无 UI 入口。用户无法主动登出，只能等待 7 天 Cookie 过期。已在侧边栏底部添加退出登录按钮。

### B3 — 侧边栏导航无激活高亮 ✅ 已修复
**文件**: `src/app/admin/(protected)/layout.tsx`

所有菜单项视觉相同，无法区分当前页面。已通过 `usePathname()` 为当前页菜单项附加激活样式。

### B4 — `createInitialJob` 初始 `publishStatus` 语义错误 ✅ 已修复
**文件**: `src/lib/sync/orchestrator.ts`

初始状态使用 `publishStatus: 'pending'`，但 `pending` 语义为"已同步、待发布"，而此时任务处于 `queued` 状态，尚未同步任何数据。已修复为 `publishStatus: undefined`，改在同步阶段完成后赋值。

### B5 — `rate-limit.ts` 内存泄漏 ✅ 已修复
**文件**: `src/lib/admin/rate-limit.ts`

`loginAttempts` Map 中过期的 key 仅在同一个 key 再次被访问时清理，大量不同 IP 的尝试会导致 Map 持续增长。已添加定时清理机制（每小时一次）。

### B6 — 生产环境未检查默认密码 ✅ 已修复
**文件**: `src/lib/admin/session.ts`

`ADMIN_PASSWORD` 使用默认值 `'admin'` 时生产环境无任何警告。已添加启动时检查并打印 warning。

### B7 — 旧版 `/api/admin/sync` 路由标记已废弃 ✅ 已修复
**文件**: `src/app/api/admin/sync/route.ts`

旧版 `POST action=trigger/update` API 与新版 `/jobs`、`/config` 路由并存，维护边界不清。已在路由头部添加废弃注释，统一引导至新接口。

### B8 — `getSyncJobs` limit 参数无上限校验 ✅ 已修复
**文件**: `src/app/api/admin/sync/jobs/route.ts`

传入极大数字时无保护。已添加 `Math.min(limit, 100)` 上限限制。

## 二、功能缺口

### F1 — Dashboard 缺少日志查看器 ✅ 已修复
`createSyncLogger` 将日志写入 `logs/sync/<jobId>.log`，但后台没有读取接口。已实现 `GET /api/admin/sync/jobs/[jobId]/logs` 端点，Dashboard 任务列表中各 Job 可展开查看完整日志。

### F2 — 运行中 Job 无法取消 ⏳ 待实现
运行中的 Job 无法从 UI 主动取消，只能等锁超时（30 分钟）。需在 orchestrator 引入取消信号机制后再实现。

### F3 — Content 页面功能单薄 ✅ 已修复
- 补充搜索/筛选功能
- 添加创作公示板（`creation-board.json`）和鸣谢名单（`contributors.json`）数据查看 Tab
- 故事大图 `imageUrl` 在展开详情时显示

### F4 — Job 详情 API 有但无 UI 链接 ✅ 已修复
`GET /api/admin/sync/jobs/[jobId]` 已实现，已在 Dashboard 任务列表中为 Job ID 添加可跳转的详情链接。

### F5 — 定时任务不展示下次执行时间 ✅ 已修复
已在调度配置卡片中通过 `GET /api/admin/sync/config` 返回的 `nextRunAt` 字段展示下次计划执行时间。后端 scheduler 读取 `node-schedule` 的 `nextInvocation()` 写入 runtime 摘要。
