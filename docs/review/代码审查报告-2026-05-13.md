## 已修复问题

### P1：同步依赖链配置容易漏跑 `creation_headers`

`creation_board` 依赖 `creation_headers`，但 Webhook 触发时使用 `read_local`，定时任务默认表保存也缺少依赖补齐入口。若头表内容更新，Webhook 只刷新创作主表会继续读取本地头表文件，导致前台卡片地点/角色元数据滞后。

处理结果：
- Webhook 使用 `run_dependencies`，触发 `creation_board` 时同步执行头表。
- 后台「定时任务配置」加入保存依赖策略，保存默认表时可按依赖关系自动补齐。
- 后台使用手册补齐 `creation_headers` 表和依赖说明。

### P1：Next.js `middleware` 文件约定产生后台告警

Next.js 16 构建与开发服务输出 `middleware` 文件约定弃用告警。

处理结果：
- `src/middleware.ts` 迁移为 `src/proxy.ts`。
- 导出函数名使用 `proxy`。
- 后台鉴权行为保持不变。

### P2：后台内容页触发 Turbopack NFT 动态追踪告警

后台内容页使用页面内 `path.resolve(process.cwd(), relativePath)` 读取动态路径，生产构建出现 NFT 追踪范围告警。

处理结果：
- 后台内容页复用 `src/lib/server/content-files.ts` 的静态数据读取入口。
- `npm run build` 通过且没有输出该 NFT 告警。

### P2：公告弹窗本地测试缺少飞书凭证时错误信息不够直接

未配置 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` 时，飞书接口返回 `invalid param`，浏览器弹窗只能展示上游错误。

处理结果：
- JSAPI 签名接口在调用飞书前校验必要环境变量。
- 错误变为 `缺少 FEISHU_APP_ID 或 FEISHU_APP_SECRET`，便于本地定位配置问题。
- `.env.example` 与环境搭建文档补齐公告弹窗所需变量说明。

### P2：文档与代码契约不同步

发现 API 文档仍写 `admin_session`，代码实际使用 `admin_auth`；API 文档缺少公告配置接口；环境搭建文档引用 `.env.example` 但仓库未提供模板。

处理结果：
- 新增 `.env.example`，并在 `.gitignore` 中允许提交模板。
- API 文档同步 `admin_auth`、公告接口、`creation_headers`、`SyncPublishStatus.pending`。
- 后台设计文档同步 Cookie 名称与 SameSite 策略。
- 文档索引补入本报告。
